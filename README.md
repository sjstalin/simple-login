# Smith C. D. — Portfolio

A modern, single-page developer portfolio for Smith C. D. — Software Engineer.

## ✨ Highlights

- **Animated hero** with a typing effect and an interactive particle network background
- **Glassmorphism navbar** with scroll progress bar, active-section highlighting, and a mobile slide-in menu
- **Skill cards** featuring real technology logos with hover lift effects
- **Project cards** with tech-stack tags and gradient accents
- **Accomplishments timeline** with icon markers
- **Scroll-reveal animations** throughout (respects `prefers-reduced-motion`)
- Fully responsive, no build step — plain HTML, CSS, and vanilla JavaScript

## 🚀 Running locally

Just open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## 📁 Structure

```
├── index.html   # page markup
├── styles.css   # theme + layout + animations
├── script.js    # typing effect, particles, scroll interactions
└── Assets/      # logos and tech icons
```
